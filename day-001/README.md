# 100 Days: Software Engineering → Security Research

A 100-day journey from programming fundamentals to software engineering,
web engineering, and security research.

## Goal

The goal isn't to memorize vulnerabilities or security tools.

The goal is to become capable of:

- Understanding unfamiliar software
- Reasoning about program behavior
- Debugging complex systems
- Understanding operating systems and networks
- Building web applications
- Identifying trust boundaries
- Forming and testing security hypotheses
- Finding root causes
- Fixing vulnerabilities
- Writing regression tests
- Documenting security findings

## Curriculum

- [ ] Days 1–20 — Python Internals & Programming Fundamentals
- [ ] Days 21–40 — Professional Software Engineering
- [ ] Days 41–55 — Computer Science Fundamentals
- [ ] Days 56–70 — Web Engineering
- [ ] Days 71–85 — Security Fundamentals
- [ ] Days 86–100 — Security Research & Bug Bounty Methodology

## Method

Learn → Build → Break → Explain → Fix → Test → Document

## AI Rule

AI can help explain, challenge, and review my work.

I should be able to reason about the program independently before
using AI to verify my conclusions.
