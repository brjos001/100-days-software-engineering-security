Welcome to Day 10 of my Python learning journey.

Today, I am learning how to identify, investigate, and fix bugs without relying on AI to provide the answers.

Learning Objectives
Understand Python tracebacks.
Understand stack frames.
Learn how to use the Python debugger (pdb).
Understand logging.
Practice using breakpoint().
Develop a systematic debugging process.
Today's Challenge

Intentionally introduce three bugs into a Python program.

Debug each bug independently without asking AI for the solution.

Debugging Methodology

Every bug must follow this process:

Bug — Identify the problem.
Observed Behavior — Record what happened.
Hypothesis — Explain what might be causing it.
Experiment — Test your hypothesis.
Root Cause — Identify the actual cause.
Fix — Implement and verify the solution.
Daily Philosophy
Don't guess. Observe, investigate, experiment, and verify.

Debugging is not just about fixing errors. It is about understanding why software behaves the way it does.
