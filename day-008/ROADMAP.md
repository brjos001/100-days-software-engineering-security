Python Learning Roadmap
Day 10 — Debugging

Goal: Become comfortable finding and fixing bugs independently.

Phase 1: Understand Debugging Concepts
Learn what a traceback is.
Understand how to read error messages.
Identify the file name and line number.
Understand stack frames.
Understand how function calls appear in a traceback.
Phase 2: Debugging Tools
Explore Python's built-in debugger (pdb).
Learn how to set breakpoints.
Practice stepping through code.
Inspect variable values.
Learn how to use breakpoint().
Understand Python logging.
Practice logging.info().
Practice logging.warning().
Practice logging.error().
Phase 3: Practical Challenge

Create a Python program and intentionally introduce three bugs.

Requirements:

Introduce Bug 1.
Introduce Bug 2.
Introduce Bug 3.
Run the program and observe its behavior.
Investigate each bug independently.
Form a hypothesis.
Run experiments.
Identify the root cause.
Fix each bug.
Run the program again to verify the fixes.
Phase 4: Documentation

Document every bug using this structure:

Bug
↓
Observed behavior
↓
Hypothesis
↓
Experiment
↓
Root cause
↓
Fix

See journal.md.

Phase 5: Completion Criteria
Understand tracebacks.
Understand stack frames.
Use the debugger independently.
Understand logging.
Use breakpoint().
Successfully debug three intentional bugs.
Document all three investigations.
Final Objective

Develop the habit of solving programming problems through observation, logical reasoning, and experimentation rather than immediately searching for answers.
