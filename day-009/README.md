## Practical Assignment: Security Information Calculator

Build a basic Python security information calculator.

### Planned Features

1. Ask the user for their name.
2. Ask for the number of security incidents.
3. Ask for the number of systems monitored.
4. Calculate the average incidents per system.
5. Display a formatted security report.
6. Use variables and appropriate data types.
7. Handle basic type conversion.

### Example Output

```text
========================================
       SECURITY INFORMATION TOOL
========================================

Enter your name: Alex
Enter number of security incidents: 20
Enter number of systems monitored: 5

Security Report
----------------------------------------
Analyst Name: Alex
Total Incidents: 20
Systems Monitored: 5
Average Incidents Per System: 4.00

Report generated successfully!
```
