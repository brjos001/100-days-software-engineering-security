
# Day 2 – Learning Roadmap

## Variables and Data Types

### Phase 1: Understand Data Types

- [ ] Learn strings (`str`).
- [ ] Learn integers (`int`).
- [ ] Learn floating-point numbers (`float`).
- [ ] Learn booleans (`bool`).
- [ ] Practice using `type()`.

### Phase 2: Variable Assignment

- [ ] Create variables.
- [ ] Assign values to variables.
- [ ] Update existing variables.
- [ ] Use meaningful variable names.

### Phase 3: Type Conversion

- [ ] Convert strings to integers using `int()`.
- [ ] Convert strings to floats using `float()`.
- [ ] Convert numbers to strings using `str()`.
- [ ] Understand conversion errors.

### Phase 4: Input and Output

- [ ] Collect information using `input()`.
- [ ] Display information using `print()`.
- [ ] Practice formatted strings (f-strings).
- [ ] Combine input, variables, and calculations.

### Phase 5: Practical Assignment

**Build a Security Information Calculator**

- [ ] Collect the user's name.
- [ ] Collect the number of security incidents.
- [ ] Collect the number of monitored systems.
- [ ] Convert user input into numeric data types.
- [ ] Calculate average incidents per system.
- [ ] Display a formatted security report.
- [ ] Test with different values.
- [ ] Handle invalid input and division by zero.

### Completion Checklist

- [ ] I understand the four main Python data types.
- [ ] I can create and assign variables.
- [ ] I understand type conversion.
- [ ] I can collect and display user input.
- [ ] I completed the security calculator.
- [ ] I uploaded my work to GitHub.
